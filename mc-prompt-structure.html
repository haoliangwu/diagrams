一次 LLM 调用的完整 prompt 结构

system[0] 冻结指引 + 消息头部 m0/m1 合成消息 + 尾部真实对话。缓存前缀 system+m0 冻结，m1 易变增量，tail 每轮移动。

Cache 经济学

system + m0 冻结

  • system 指引追加进 system[0]，不新增元素
  • m0 字节缓存 cached_m0_bytes，defer 逐字节 replay
  • HARD 仅 model/system/TTL/epoch 等 10 信号

增量通道

m1 易变 · bust 在 m1 断点

  • 新 compartment/memory/profile 走 watermark
  • softRefresh 只重渲 m1，m0 不动
  • 超 15% / 40条 / 20% budget 触发 drift refold

尾部机制

tail 每轮移动

  • N tag + temporal marker 内联
  • [dropped N] → sentinel 中和保长度
  • 最新 20 tag 受保护，Channel-1/2 nudge 提醒
