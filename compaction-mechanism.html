上下文压缩机制

三条触发路径（手动 /compact、step 压力、context 溢出恢复）汇入同一条共享事务管线， 在 append-only 会话日志上以「遮蔽」而非「删除」改写模型可见历史。

压缩动作 / checkpoint 保留节点（模型可见） 遮蔽节点（日志仍在，模型不可见） 事务锁 / 生命周期 LLM 摘要调用

02

共享事务管线

compactSurfaceRegion() · compaction-basic/src/region.ts
session.append(…) · surfaceOp: replace 日志 append-only，任何「删除」都是一条新的遮蔽事件
① validateSurfaceRegion start/end 必须在 surface 上、顺序对、tool 配对平衡（不拆 call/result 对） 三条路径共用
② compaction/start 持久化锁。崩溃后 unmatched start 可检测；新压缩被拒 三条路径共用
③ prepareCompaction 重放选中区 → SummarizationInput（自己的 system + tools + messages 前缀） 三条路径共用
④ summarizeCompaction 一次 one-shot ctx.llm.stream()；前缀复用对话 → provider KV cache 不失效 三条路径共用
⑤ assertStable 摘要期间 surface 变化 → SurfaceChangedError。手动=selected-span；自动=whole-surface 三条路径共用
⑥ commitCompactionBody append checkpoint + surfaceOp: {op:'replace', start, end} + sourceEventSeqs 覆盖每个遮蔽节点 三条路径共用
⑦ compaction/end · flush 解锁。失败留 error 标记。手动路径显式 ctx.sessions.flush() 落盘 三条路径共用

04

配置默认值

compaction-basic/src/config.ts · 点击触发卡联动高亮
字段默认值作用于说明
thresholdRatio 0.8 pressure 压力阈值 = contextWindow × 0.8，超了才触发自动压缩
retainRatio 0.16 pressure 保留尾部 = contextWindow × 0.16，之前全部压成摘要
retainTokens undefined pressure / manual 未设走 retainRatio；设了则固定 token 数（二选一）。manual 路径写死 0
summarizationProvider / Model ''（空） 三条路径 空 = 用会话当前路由的 provider/model
maxTokens 8192 三条路径 摘要调用输出上限
compactionRetries 1 pressure 压一次后仍超阈值，最多再压 1 次（共 2 次尝试）
maxOverflowRetries 1 overflow context-overflow 恢复最多重试 1 次
auto true pressure / overflow 开关 pre-step 压力 + overflow 恢复的自动注册
modelPolicies [] pressure 按 {provider, model} 精确覆盖默认值；未覆盖字段继承顶层
contextWindow ● adapter 定义 — 不是 compaction 配置：llm 层 model 属性，compaction 只读（resolveModelInfo）
CONTEXT_WINDOW_EXCEEDED ● 写死 overflow provider 协议常量（HarnessError code），非配置项

● 固定项：非 compaction 配置。
配置位置：cordis.patch.yml 中 compaction-basic 插件行的 config:（顶层默认 + modelPolicies[] 两级）。
